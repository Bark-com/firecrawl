# Installing and Using the Customized Firecrawl Python SDK

## Overview

Our self-hosted Firecrawl deployment includes a customized Python SDK with additional cost tracking features. This document explains how to install it and use both v1 and v2 APIs, with comprehensive coverage of cost tracking capabilities.

---

## Important: v1 vs v2 API

| Aspect | v1 API | v2 API |
|--------|--------|--------|
| **API endpoint** | `/v1/extract` | `/v2/extract` |
| **Self-hosted compatible** | ✅ Yes (uses Redis) | ⚠️ Requires Supabase |
| **Response field naming** | camelCase (`costTracking`) | snake_case (`cost_tracking`) |
| **Recommended for** | Self-hosted deployments | Firecrawl Cloud |

> ⚠️ **For self-hosted deployments without Supabase, use the v1 API.**

### Why v2 Requires Supabase

The v2 API's `extract-status` endpoint relies on Supabase for job lookup:

```typescript
// v2 controller - requires Supabase
const extractRequest = await supabaseGetExtractRequestByIdDirect(req.params.jobId);
if (!extractRequest) return 404;  // Fails without Supabase!
```

The v1 API uses Redis instead, making it self-hosted compatible:

```typescript
// v1 controller - uses Redis (self-hosted compatible)
const extract = await getExtract(req.params.jobId);  // Works!
```

## SDK Client Overview

The SDK provides multiple ways to access the APIs:

| Client Class | Default API | v1 Access | v2 Access |
|--------------|-------------|-----------|-----------|
| `FirecrawlApp` (unified) | **v2** | `app.v1.extract()` | `app.extract()` |
| `AsyncFirecrawlApp` (unified async) | **v2** | `app.v1.extract()` | `app.extract()` |
| `V1FirecrawlApp` (v1 only) | v1 | `app.extract()` | N/A |
| `AsyncV1FirecrawlApp` (v1 only async) | v1 | `app.extract()` | N/A |
| `FirecrawlClient` (v2 only) | v2 | N/A | `client.extract()` |
| `AsyncFirecrawlClient` (v2 only async) | v2 | N/A | `client.extract()` |

**For self-hosted**, use one of these patterns:
```python
# Option 1: Unified client with v1 access
from firecrawl import FirecrawlApp
app = FirecrawlApp(api_key="fc-test", api_url="http://localhost:3002")
result = app.v1.extract(...)  # Uses /v1/extract

# Option 2: Pure v1 client
from firecrawl import V1FirecrawlApp
app = V1FirecrawlApp(api_key="fc-test", api_url="http://localhost:3002")
result = app.extract(...)  # Uses /v1/extract
```

## What's Customized?

Both v1 and v2 APIs have been extended with cost tracking:

| Feature | v1 API | v2 API |
|---------|--------|--------|
| Enable cost tracking | `show_cost_tracking=True` | `show_cost_tracking=True` |
| Verbosity control | `cost_tracking_verbosity="detailed"` | `cost_tracking_verbosity="detailed"` |
| Total cost | `result.costTracking.totalCost` | `result.cost_tracking.total_cost` |
| Total calls | `result.costTracking.totalCalls` | `result.cost_tracking.total_calls` |
| Input tokens | `result.costTracking.totalInputTokens` | `result.cost_tracking.total_input_tokens` |
| Output tokens | `result.costTracking.totalOutputTokens` | `result.cost_tracking.total_output_tokens` |
| Per-call breakdown | `result.costTracking.calls` | `result.cost_tracking.calls` |

> **Note:** `show_llm_usage` / `llmUsage` are deprecated. Use `show_cost_tracking` instead.

### Cost Tracking Verbosity Levels

| Level | Description | Fields Included |
|-------|-------------|-----------------|
| `"summary"` | Aggregate totals only | `totalCalls`, `totalInputTokens`, `totalOutputTokens`, `totalCost` |
| `"detailed"` | Totals + per-call breakdown | Summary + `calls[]` (without stack traces) - **Default** |
| `"full"` | Everything including debug info | Summary + `calls[]` (with stack traces for debugging) |

### Understanding Firecrawl Internal Fields

⚠️ **Important:** These fields are NOT related to LLM token usage:

- **`tokensUsed`**: `JSON.stringify(result).length / 4 + 300` (based on output size)
- **`creditsUsed`**: `Math.ceil(tokensUsed / 15)` (Firecrawl's proprietary billing)

For actual LLM cost tracking, use:
- `costTracking.totalInputTokens` - Actual input tokens sent to LLMs
- `costTracking.totalOutputTokens` - Actual output tokens generated by LLMs
- `costTracking.totalCost` - Total cost in USD for all LLM calls

## Installation Methods

### Method 1: From Git (Recommended)

Install directly from your Firecrawl fork:

**Using pip:**
```bash
pip install "firecrawl-py @ git+https://github.com/YOUR_ORG/firecrawl.git@main#subdirectory=apps/python-sdk"
```

**Using uv:**
```bash
uv add "firecrawl-py @ git+https://github.com/YOUR_ORG/firecrawl.git@main#subdirectory=apps/python-sdk"
```

### Method 2: In Requirements File

**requirements.txt:**
```txt
firecrawl-py @ git+https://github.com/YOUR_ORG/firecrawl.git@main#subdirectory=apps/python-sdk
```

**pyproject.toml:**
```toml
[project]
dependencies = [
    "firecrawl-py @ git+https://github.com/YOUR_ORG/firecrawl.git@main#subdirectory=apps/python-sdk",
]
```

### Method 3: Pin to Specific Commit (Production)

For reproducible builds, pin to a commit hash:

```txt
firecrawl-py @ git+https://github.com/YOUR_ORG/firecrawl.git@a1b2c3d4e5f6#subdirectory=apps/python-sdk
```

### Method 4: Local Development

For active development on both SDK and your project:

```bash
pip install -e /path/to/firecrawl/apps/python-sdk
```

## Usage Examples

### v1 API - Using Unified Client (`FirecrawlApp.v1`)

**Recommended for self-hosted deployments.**

```python
from firecrawl import FirecrawlApp

# Connect to self-hosted Firecrawl
app = FirecrawlApp(
    api_key="fc-test",
    api_url="http://localhost:3002"
)

# Extract using v1 API (note: app.v1.extract, not app.extract!)
result = app.v1.extract(
    urls=["https://example.com/*"],
    prompt="Extract company information",
    schema={
        "type": "object",
        "properties": {
            "name": {"type": "string"},
            "description": {"type": "string"},
            "services": {"type": "array", "items": {"type": "string"}}
        }
    },
    limit=5,
    show_sources=True,
    show_cost_tracking=True,
    cost_tracking_verbosity="detailed",  # "summary", "detailed", or "full"
)

# Access extracted data
print(f"Success: {result.success}")
print(f"Data: {result.data}")

# Access cost tracking (v1 uses camelCase!)
if result.costTracking:
    print(f"\n=== Cost Tracking ===")
    print(f"Total LLM calls: {result.costTracking.totalCalls}")
    print(f"Input tokens: {result.costTracking.totalInputTokens}")
    print(f"Output tokens: {result.costTracking.totalOutputTokens}")
    print(f"Total cost: ${result.costTracking.totalCost:.6f}")
    
    # Per-call breakdown
    if result.costTracking.calls:
        print(f"\nPer-call breakdown:")
        for call in result.costTracking.calls:
            tokens = call.tokens or {}
            print(f"  - {call.model}: ${call.cost:.6f} "
                  f"({tokens.get('input', 0)} in, {tokens.get('output', 0)} out)")
```

### v1 API - Async Job with Manual Polling

```python
from firecrawl import V1FirecrawlApp
import time

app = V1FirecrawlApp(api_key="fc-test", api_url="http://localhost:3002")

# Start async job (returns immediately with job ID)
job = app.async_extract(
    urls=["https://example.com/*"],
    prompt="Extract company info",
    schema={"type": "object", "properties": {"name": {"type": "string"}}},
    limit=5,
    show_cost_tracking=True,
    cost_tracking_verbosity="detailed",
)

print(f"Job started: {job.id}")

# Poll for completion
while True:
    status = app.get_extract_status(job.id)
    print(f"Status: {status.status}")
    
    if status.status == "completed":
        print(f"Data: {status.data}")
        # v1 uses camelCase!
        if status.costTracking:
            print(f"Cost: ${status.costTracking.totalCost:.6f}")
        break
    elif status.status == "failed":
        print(f"Error: {status.error}")
        break
    
    time.sleep(2)
```

## Troubleshooting

### "cost_tracking_verbosity is not a valid parameter"

The official PyPI package is installed instead of your custom version.

**Fix:**
```bash
pip uninstall firecrawl-py
pip install "firecrawl-py @ git+https://github.com/YOUR_ORG/firecrawl.git@main#subdirectory=apps/python-sdk"
```

### "result.costTracking is None" (v1) or "result.cost_tracking is None" (v2)

The server-side flags weren't set or the API isn't returning cost data.

**Check:**
1. Ensure `show_cost_tracking=True` is passed to `extract()`
2. Verify your Firecrawl API has the cost tracking patches applied
3. Check that `__experimental_showCostTracking` appears in the request body

### v2 extract returns 500 error or "Extract job not found"

The v2 API requires Supabase which isn't configured in your self-hosted setup.

**Fix:** Use the v1 API instead:
```python
# Instead of (v2 - default):
app = FirecrawlApp(...)
result = app.extract(...)  # Uses v2!

# Use (v1):
app = FirecrawlApp(...)
result = app.v1.extract(...)  # Uses v1!

# Or use the pure v1 client:
from firecrawl import V1FirecrawlApp
app = V1FirecrawlApp(...)
result = app.extract(...)  # Uses v1!
```

### Authentication errors with private repo

**For SSH:**
```bash
ssh -T git@github.com  # Test SSH connection
```

**For HTTPS:**
```bash
# Ensure token has repo access
curl -H "Authorization: token ${GITHUB_TOKEN}" https://api.github.com/user
```
